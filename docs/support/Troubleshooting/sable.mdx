## Crashing while loading into a world (Windows)

If you are experiencing crashes while loading into a world and you get an `hs_err_pid` file, try the following steps:

1. Open the hs_err_pid file in a text editor and look for a line that says `EXCEPTION_UNCAUGHT_CXX_EXCEPTION`. If you see this line continue to follow the steps below.
2. Open where the modpack is installed and navigate to the `.sable` > `natives` folder.
    - Opening the folder can often be done by right clicking the modpack in the launcher and selecting "Open Folder".
3. Delete the `sable_rapier_x86_64_windows.dll` file.
4. Restart the game and see if the issue is resolved.
